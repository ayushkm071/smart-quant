# Smart-Quant

Smart-Quant is a quantitative finance project focused on financial time series forecasting.

## Project Goal

Analyze financial market data and build models that predict trends.

## Current Features

• ARIMA based time series forecasting  
• Data preprocessing in Python  
• Visualization of predictions

## Future Work

• XGBoost model  
• LSTM neural network  
• Portfolio optimization  
• Risk analysis

## Technologies Used

Python  
ARIMA  
NumPy  
Pandas  
Matplotlib
